Motor de sincronización de calendarios iCal para prevenir overbooking en plataformas de alquiler vacacional.

## 🚀 Características

- ✅ Sincronización automática con Airbnb, Vrbo, Booking
- ✅ Detección de conflictos de fechas (overlaps)
- ✅ Base de datos SQLite embebida
- ✅ Alto rendimiento (escrito en Rust)
- ✅ Bajo consumo de memoria
- ✅ Ejecución en segundo plano 24/7

## 📦 Instalación

```bash
git clone https://github.com/srwangcr/ical_prototype.git
cd ical_prototype
